# pdf-tools

PDFの加工を1つにまとめたブラウザ完結ツール（Cloudflare Pages・静的サイト）。旧 `pdf-redactor` / `pdf-metadata` / `pdf-merge` を統合し、デザインは `sidenote` のヒーロー＋ボタン切り替え構成を踏襲しています。

ヒーローの「機能」ボタン（sidenoteの「デザイン」ボタンと同じ位置・見た目）で6機能を切り替えます。選択は `#redact` `#hand` `#pages` `#meta` `#shrink` `#pageno` のURLハッシュと localStorage に保存されます。

| ボタン | 内容 | 実装 |
|---|---|---|
| 墨消し・検索 | 文字検索・ドラッグで墨消し枠→画像化して黒塗り | `public/redact.js`（旧 pdf-redactor） |
| 手書き風文字追加 | 手書き風書体の文字・四角・マル・波かっこ「{ }」・矢印を配置、消しゴム（新規） | `public/hand.js` |
| 結合・分割・回転 | 結合・並べ替え・削除・回転・選択抽出・Nページごと分割 | `public/pages.js`（旧 pdf-merge＋新機能） |
| メタデータ編集削除 | 文書プロパティの編集・削除、フォルダ一覧編集 | `public/meta.js`（旧 pdf-metadata） |
| 縮小・配置 | 各ページを指定の％に縮小し、同じ用紙サイズの左上・上中央・中心など9か所へ置く（新規） | `public/shrink.js` |
| ページ番号 | 「1」「1頁」「1ページ」「p.1」「1 / 全体」などを、左上・右下など6か所へ。書体は標準／手書き風（新規） | `public/pageno.js` |

共通処理は `public/common.js`（遅延描画ビューア `PageViewer` など）、切り替えは `public/app.js`。

## 手書き風文字追加について
- 書体は Google Fonts（Yomogi / Klee One / Zen Kurenaido / Yusei Magic）。読み込むのはフォント定義のみで、PDFは送信されません。
- 1文字ずつ位置・角度・大きさを少しずらして「手書き風」にしています（ゆらぎ・傾きはスライダー）。
- 保存時は文字を透明PNGにして元ページの上に重ねます（元PDFの内容は維持、追加文字は選択・検索不可）。回転ページにも対応。
- 設定メニュー（配置するもの・書体・色など）は画面上部に固定され、ページをスクロールしても使えます。固定中は詰めた表示になり、「メニューを固定」を外すと通常の位置に戻ります（選択はこのブラウザに保存）。
- 置いた要素を選ぶと四隅（文字は右下）につまみが出て、ドラッグで大きさを変えられます。文字の大きさは「大きさ（pt）」の数値でも指定できます（6〜300pt）。
- 波かっこ「{ }」と矢印は、四角・マルと同じくドラッグで範囲を決めて置きます（矢印はドラッグした向きに引く）。線のゆらぎ・消しゴムも共通です。線の太さは0.25〜12で、細い線も引けます。

## 縮小・配置について
- 元ページを画像にせず、そのまま埋め込んで縮小します（文字は選択・検索可のまま）。用紙サイズは変わらず、縮めた分が余白になります。
- 倍率は20〜100％、位置は9か所。向きを変えた（`/Rotate`）ページも見た目の位置に合わせます。

## ページ番号について
- 「頁」「ページ」はPDF標準フォントに無いため、番号は画像にして重ねます（選択・検索不可）。手書き風書体を選ぶと、「手書き風文字追加」と同じく1文字ずつ・行ごとにゆらぎます（傾き−15〜15度も指定可）。
- 「何ページ目から付けるか」「最初の番号」で、表紙を飛ばす・途中から振り直す、ができます。
- 書式の「手入力」では自動の番号を使わず、ページを見ながら1ページずつ文字（例：「10月1日（1-1）」）を入力します。Enterで改行（複数行は置く位置に合わせて左・中央・右にそろえます）、Ctrl+Enterか「次のページ」でめくれ、空欄のページには入れません。位置・書体・大きさは他の書式と共通です。
- 自動で振るときの番号の付け方は「連番」「章-ページ（1-1, 1-2, 2-1…。各章の最初のページを入力）」から選べます。

## 共通の操作
- 「PDFを選ぶ」は、どの機能でも画面上部のボタン（またはドラッグ＆ドロップ）です。
- 画面を下へスクロールして機能ボタン（トップメニュー）が見えなくなると、右下に「↑」ボタンが出ます。押すとメニューの位置へ戻ります（sidenoteと同様）。
- 「手書き風文字追加」と「ページ番号」には、作業の途中で保存して続きから編集する機能があります（sidenoteと同様）。「ファイルを保存」で作業を.jsonに保存し（元のPDFもファイルの中に入るので、PDFが大きいと.jsonも大きくなります）、「ファイルを開く」で続きを編集します。仕上げのPDFは「PDFを保存」です。.jsonの中身は読み込み時に形と範囲を確かめ、別の機能の.jsonや壊れた.jsonは開きません。
- 保存は、保存先を選べるブラウザ（Chrome・Edgeなど）では「名前を付けて保存」の画面が出ます。分割・まとめて保存は、フォルダを1回選ぶだけで全ファイルを書き出します。未対応のブラウザでは通常のダウンロードです。
